# APK 打包与真机运行说明

> 本说明针对「基于 uni-app 的智能记账与生活便签一体化管理系统」。
> 代码层已做真机适配（服务器地址可配置、旧 WebView 兼容回退），但 APK 的实际打包与安装必须在
> HBuilderX 中完成（需要 DCloud 账号与云打包）。

## 一、打包前必须完成的事

### 1. 替换 DCloud appid
`frontend/manifest.json` 中的 `appid` 目前是占位值 `__UNI__SMARTLIFE`。
用 HBuilderX 打开项目 → 双击 `manifest.json` → 「基础配置」→ 点击「重新获取」生成真实 appid
（需登录 DCloud 账号）。没有真实 appid 无法云打包。

### 2. 后端监听局域网
默认启动只监听本机，手机无法访问。请改为：

```bash
cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

- 手机与电脑必须连接**同一个 Wi-Fi**
- 电脑上执行 `ipconfig` 查看 IPv4 地址（如 `192.168.1.100`）
- Windows 防火墙需要放行 8000 端口（首次访问时在弹窗中允许，或手动添加入站规则）
- 快速验证：手机浏览器打开 `http://电脑IP:8000/api/health`，能看到 `{"ok":true,...}` 即可

### 3. 在 App 内填写服务器地址
打开 App 的**登录页 → 底部「服务器设置（真机调试用）」**，填入：

```
http://电脑IP:8000
```

保存后立即生效（登录后也可在「我的 → 服务器地址」修改）。
该地址保存在手机本地，不需要重新打包。

### 4. AI 功能
模型密钥只配置在电脑的后端 `.env`，手机端不需要、也不应该配置密钥。
手机通过后端调用 AI；电脑上的后端保持运行即可。

## 二、打包步骤（HBuilderX）

1. 用 HBuilderX 打开 `frontend/` 目录
2. 确认能在 H5 正常预览（运行 → 运行到浏览器）
3. 发行 → 原生 App-云打包
4. 平台选择 Android；证书可用「DCloud 公用证书」（课程演示够用）
5. 打包完成后下载 APK，安装到手机

## 四、常见问题

1. **所有请求失败 / “网络连接失败”**
   - 检查手机与电脑是否同一 Wi-Fi
   - 检查 App 内服务器地址是否为 `http://电脑IP:8000`（不是 127.0.0.1）
   - 检查后端是否用 `--host 0.0.0.0` 启动、防火墙是否放行
2. **Android 9+ 提示明文 HTTP 被禁止**
   课程演示可将 `manifest.json` 的 Android `targetSdkVersion` 设为 28 后重新打包，
   或给后端配置 HTTPS（如内网穿透）。正式发布建议使用 HTTPS。
3. **截图识别上传失败**
   检查是否授予了相册/相机权限；Android 端首次使用会弹权限请求。
4. **环形图显示为纯色圆**
   极旧的安卓 WebView 不支持 conic-gradient，已做纯色回退，不影响数据。
5. **AI 接口 503**
   后端 `.env` 未配置模型密钥，或电脑后端未启动；手机端不配置密钥。

## 五、性能与兼容性说明

- 推荐 Android 8.0 及以上（系统 WebView 较新，CSS Grid / conic-gradient / 模糊效果支持良好）
- 已做兼容处理：`String.prototype.padStart` 补丁、环形图纯色回退、取消磨砂玻璃减少渲染开销
- 所有数据都存于后端 MySQL/SQLite，卸载 App 不会丢数据（服务器数据仍在）
